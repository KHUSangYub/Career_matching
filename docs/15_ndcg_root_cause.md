# exp-021: NDCG 0.998 원인 분석

> 내 연구 관점에서의 핵심 takeaway
> - **어느 차별성 축에 연결되는가:** ④ GT 부재 평가 방법론 — *saturation·circularity 진단이 본 연구의 핵심 기여*
> - **무엇을 강화하는가:** "NDCG 0.998이 왜 높은가"를 3가지 가설로 정량 검증. 순환성(H1)이 주원인임을 수치로 확정. 심사위원 질문에 논리적으로 대응 가능한 근거 확보.
> - **영향 부위:** 평가 프레임워크 (순환성 진단 → 독립 라벨 정당화)
> - **당장 가져갈 1개 액션:** 논문 §실험 설계에 "순환성 인플레이션 추정: +0.078p" 수치와 H1~H3 결과 표를 명시. 이게 차별성 ④의 핵심 증거.

## 한 줄 요약

NDCG 0.998의 주원인은 **라벨-스코어 순환성** (+0.078p 인플레이션). 풀 크기·N 크기는 영향 미미.

## 실험 설계

| 항목 | 내용 |
|---|---|
| 데이터 | user_data.csv (999명) × company_jobdescription_enriched.partial.csv (3,000 JD 전체) |
| 가중치 | exp-018의 golden / learned / arbitrary (그대로 재사용) |
| 라벨 | 순환 라벨 (exp-018과 동일 rule) + 독립 라벨 (exp-019/020 인용) |
| 코드 | `output/exp-021-ndcg-root-cause-analysis.ipynb` |

**3가지 가설:**

| 가설 | 내용 | 검증 방법 |
|---|---|---|
| H1 | 라벨-스코어 순환성: label과 score가 동일 5컴포넌트에서 파생 | Spearman(score, label) 계산 |
| H2 | 풀 크기 포화: 소규모 pool에서 easy negative 천장 효과 | pool 50→3k NDCG 곡선 |
| H3 | N 부족 분산: 유저 수 적어 CI 넓음 | Bootstrap N=6→999 |

## 핵심 결과

### H1: 라벨 순환성 (주원인 확정)

**Spearman(score, circular_label):**

| 관점 | arbitrary | golden | learned |
|---|---|---|---|
| A | 0.7903 | 0.6607 | 0.6604 |
| B | 0.8183 | **0.9107** | **0.9082** |
| C | 0.7179 | **0.9397** | **0.9393** |
| D | 0.6439 | 0.6441 | 0.6585 |
| E | 0.6847 | 0.6847 | 0.7101 |
| **평균** | **0.731** | **0.768** | **0.766** |

> ⚠️ B·C 관점에서 Spearman 0.91~0.94
> - 라벨 함수와 스코어 함수가 **동일한 5컴포넌트 c**에서 파생되어 구조적으로 상관관계가 높음
> - 특히 B(star 중심)·C(skill/comp 중심) 관점에서 golden weight가 라벨러 가중치와 거의 동일한 방향을 학습 → Spearman 폭발

**순환성 인플레이션 정량화:**

| 평가 | N_users | pool | arbitrary | golden | learned |
|---|---|---|---|---|---|
| 순환 라벨 exp-018 | 199 | 3k | 0.9361 | 0.9984 | 0.9959 |
| **순환 라벨 exp-021 (전체)** | **999** | **3k** | **0.9355** | **0.9983** | **0.9956** |
| 독립 라벨 exp-019 | 6 | 10 | 0.9165 | 0.9165 | 0.9057 |
| 독립 라벨 exp-020 | 12 | 10 | 0.9204 | 0.9204 | 0.9184 |

**순환성 인플레이션 추정: golden 0.9983 − 0.9204 = +0.0779p**

### H2: 풀 크기 민감도 (영향 미미)

| pool 크기 | NDCG@10 (golden) |
|---|---|
| 50 | 0.9922 |
| 100 | 0.9946 |
| 200 | 0.9958 |
| 500 | 0.9972 |
| 1,000 | 0.9985 |
| 2,000 | 0.9983 |
| **3,000** | **0.9982** |

> 풀 크기 50→3,000 NDCG 변화 +0.006p
> 풀 크기는 NDCG를 거의 변화시키지 않는다. 순환 라벨 아래에서는 positive/negative 구분이 매우 명확하여 pool이 커져도 NDCG가 유지된다. **H2는 기각.**

### H3: N 유저 분산 (영향 없음)

| N_users | NDCG 평균 | std | 95% CI |
|---|---|---|---|
| 6 | 0.9983 | 0.0011 | [0.9956, 1.000] |
| 12 | 0.9984 | 0.0008 | [0.9963, 0.9996] |
| 30 | 0.9983 | 0.0005 | [0.9973, 0.9992] |
| 60 | 0.9982 | 0.0004 | [0.9975, 0.9990] |
| 100 | 0.9983 | 0.0003 | [0.9978, 0.9988] |
| 199 | 0.9983 | 0.0002 | [0.9979, 0.9986] |
| **999** | **0.9983** | **0.0000** | **[0.9983, 0.9983]** |

> N=6이든 999이든 NDCG≈0.998, std<0.001
> 순환 라벨 아래에서는 유저 수가 NDCG에 거의 영향을 미치지 않는다. **H3는 기각.** (단, 독립 라벨 환경에서는 다를 수 있음)

### 전체 데이터 최종 공식 수치 (999명 × 3,000 JD)

| 관점 | arbitrary | golden | learned |
|---|---|---|---|
| A | 0.9953 | 0.9996 | 0.9998 |
| B | 0.9285 | 0.9986 | 0.9927 |
| C | 0.7846 | 0.9964 | 0.9936 |
| D | 0.9722 | 1.0000 | 1.0000 |
| E | 0.9967 | 0.9967 | 0.9919 |
| **MEAN** | **0.9355** | **0.9983** | **0.9956** |

> 199명→999명 확장해도 NDCG 변화 없음 (0.9984→0.9983)
> 교수님이 요청한 "전체 데이터로 돌려도 점수가 낮아지는가" → **NO**. 하락 없음. 이유: 순환성이 N 크기와 무관하게 NDCG를 구조적으로 높게 유지하기 때문.

## 수학적 설명 (심사 대비 논리)

라벨 함수: `label = f(w_label · c)` (5컴포넌트 c의 단조 함수)  
스코어 함수: `score = w_score · c` (동일 c의 선형 함수)

두 함수가 동일한 `c`를 공유하므로 **Spearman(score, label) ≈ 0.77 (구조적 상관)**. golden weights는 NDCG를 최대화하도록 최적화되었으므로, score ranking ≈ label ranking → NDCG → 1.0.

이것이 **평가 순환성(evaluation circularity)**의 정의이며, 본 연구의 핵심 기여가 이를 *진단·완화*하는 독립 평가 방법론(`docs/13_independent_eval.md`, `docs/14_independent_eval_stats.md`)이다.

## 결론: 3가지 원인 기여도

| 원인 | 기여도 | 근거 |
|---|---|---|
| **H1 라벨 순환성** | **★ 주원인** (+0.078p 인플레이션) | 순환-독립 NDCG gap |
| H2 풀 크기 | 무시 가능 (+0.006p) | pool 50→3k curve |
| H3 N 분산 | 무시 가능 (std<0.001) | bootstrap |

## 내 연구에의 적용

- **평가 프레임워크:** 순환성 인플레이션 +0.078p를 정량화했으므로 논문 §실험에 "순환 라벨 기준 NDCG=0.998은 독립 라벨 기준 0.920 대비 +0.078p 과대 추정"으로 명시 가능
- **자기소개서 파이프라인:** 5컴포넌트 기반 rule labeler의 한계 확인 → LLM 독립 채점의 정당성 강화
- **Dual Encoder / 매칭:** golden > arbitrary (0.998 vs 0.936 순환 / 0.920 vs 0.920 독립) → 순환 기준 격차는 인위적, 독립 기준 격차 없음

## 한계 · 비판 · 모순

> ⚠️ 
> - 독립 라벨 기준 NDCG 0.920이 "진짜 성능"인지도 불확실 — exp-019/020의 pool=10(10쌍)으로 측정한 값. 3k pool + 독립 라벨 대규모 평가가 필요 (V2 과제)
> - Spearman 0.768은 *전체 평균* — 관점별 편차 크다(A·D ≈ 0.65, B·C ≈ 0.92). 관점별 순환성 강도가 다르므로 일괄 해석 주의
